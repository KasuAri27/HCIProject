# 简短 PR 填写示例

创建 PR 前先阅读[统一模板](../.github/pull_request_template.md)，每节 1～2 句，详细说明放链接。

## CI 分支

标题：`ci: 补齐前后端质量门禁`

```markdown
## 内容
补齐前端运行、后端转换/OCR、启动器、提交规范与密钥检查；合并后自动删除来源分支。

## 验证
main 副本单测和浏览器测试通过；真实 Office/OCR 与故障阻断已验证，CI 结果见检查页。

## 注意
第六项提交范围回退暂缓；Office 远端验收需要自托管 runner。
```

## 文档分支

标题：`docs: 精简 PR 模板与贡献规范`

```markdown
## 内容
启用三节简短 PR 模板，要求贡献者先阅读，并明确合并后删除来源分支。

## 验证
模板格式、文档链接与差异检查通过。

## 注意
建议先合并 CI PR，使新正文门禁和自动清理工作流生效。
```
