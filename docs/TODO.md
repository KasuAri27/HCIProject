# 学习软件扩展 TODO

目标：本地资料学习工作台。导入后按类型进入阅读：PDF 播放原版面，PPTX/DOCX 转 PDF 播放，Markdown/TXT 渲染 Markdown；AI 可选，不配置也能阅读、标注和记笔记。

## 后端已完成（重点）

- **资料库与版本**：SQLite 保存文档/版本/章节/内容块，使用稳定文档 ID；原文件、PDF 播放文件和旧版本都保留，改名不丢学习记录。
- **导入与解析**：MD/TXT 解析为 Markdown；PDF 直接播放；DOCX/PPTX 用本机 Microsoft Office 转 PDF 后播放；扫描 PDF 支持 OCR；后台任务、进度与失败重试。
- **阅读与学习**：PDF/Markdown 两种阅读模式；Markdown 模式支持位置恢复、高亮标注、笔记撤销/导出、读后自评、理解检查与练习证据。
- **AI 助教**：统一上下文与引用白名单；划段解释、举例、补前置、理解检查；跨资料检索与带来源引用的问答。AI 失败不阻塞阅读。
- **数据安全**：旧数据迁移与备份；新版本清理前置题缓存，旧版本和学习记录保留并提示引用风险。

## 限制

- PDF 播放模式不记录滚动位置，也不能划选标注；AI 与全文检索仍使用抽取出的文本。
- DOCX/PPTX 转 PDF 依赖 Windows + 本机 Microsoft Office；转换失败会明确报错，已有资料可能回退为文本预览。
- PPTX 图表数据、嵌入公式和动画不解析；扫描 PDF 的 OCR 需要 Tesseract 与 `chi_sim` 语言包。
- 旧版本不提供切换阅读界面；引用失效时会提示“来自旧版本”。
