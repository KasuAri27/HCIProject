# 前端美化建议

面向大学生阅读课件、教材的本地学习工作台。基于提交 `c3c839b` 及第三、四阶段提交、README、TODO、架构文档和当前页面整理。本轮聚焦视觉表现，沿用现有功能、三栏布局和阅读流程。

建议延续“纸面阅读＋青色批注”的风格：白色正文是视觉中心，冷灰侧栏承载工具，青色用于选中项与引用标记。当前基础已经清楚，主要打磨字体、留白、对齐与组件一致性。

| 美化部分 | 建议 |
|---|---|
| 整体配色 | 保留青色主调，减少相近灰色的零散使用。正文、工具栏、桌面背景形成三层明度；提示色只表达状态，避免大面积渐变和发光效果。 |
| 字体层级 | 界面使用微软雅黑／苹方等本地无衬线字体；阅读正文保留宋体风格。引用与正文统一字体，通过缩进和边线区分，减少楷体、宋体、无衬线在小区域内混用。等宽字体留给代码，路径和时间使用界面字体。 |
| 辅助文字 | 当前部分状态、来源和徽章只有约 10–11px，且颜色偏淡。建议正文 17–18px、界面 14px、辅助文字 12–13px；通过字号、字重和位置体现次要层级，避免靠低对比度弱化文字。 |
| 正文纸面 | 当前左侧内边距为 80px，三栏显示时正文偏窄。建议常规桌面内边距收敛到 32–40px，淡化装订线和投影；标题、段落、列表统一左对齐，正文行距约 1.75–1.9，中文每行约 25–38 字作为调校起点。 |
| 顶栏与文档标题栏 | 按钮高度、文字基线和组间距统一。标题区先保证资料名可读；空间不足时让工具区整组换行，避免标题被按钮挤成短小碎片。主操作用实色，辅助操作用描边或透明底。 |
| 资料柜与搜索结果 | 统一列表行高和左右内边距；资料名、格式徽章与状态标记整齐对齐。选中项使用浅青底和细侧边标记，搜索摘要保持两级文字层次，避免结果区出现多层嵌套边框。 |
| 对话、笔记与练习 | 五个标签页共用一致的标题行、工具行和内容边距。输入区保留白底与细边框，区块间用 16–24px 留白；引用、题目、反馈的标题字号和段间距统一，减少边线与空白叠加。 |
| 按钮、表单与图标 | 常规控件高度以 34–36px 为起点，紧凑工具控件约 28–30px；圆角统一为控件 4px、面板／弹窗 8px。沿用现有线性 SVG，统一到 16–18px；悬停、选中、禁用和焦点样式成套定义。 |
| 弹窗、空状态与提示 | 设置弹窗的标签、输入框和底部操作按同一网格对齐，内边距约 24px。空状态采用简短标题和说明；保存提示、版本提醒和错误提示统一字体及间距，保留各自状态色。 |
| PDF 阅读区域 | 统一 PDF 外围的标题栏、边界和桌面底色，使其与 Markdown 阅读区协调。浏览器内置 PDF 工具栏及原文件版式不由页面 CSS 控制，本轮美化范围限定在外围容器。 |

配色建议沿用现有变量，收敛为六个基础值：桌面 `#E9EDF1`、纸面 `#FFFFFF`、侧栏 `#F5F7F9`、正文 `#1B2530`、辅助文字 `#5D6D78`、强调色 `#0F6E7C`。边线、浅色选中底和成功／警告／错误色统一通过语义变量管理。

字体优先使用本机字体，保证离线可用；若后续需要更稳定的中文宋体效果，可随应用本地打包思源宋体。标题建议采用 24／20／18px 梯度；不在标题内额外强调单个词。间距统一使用 4／8／12／16／24／32px 层级，阴影主要用于纸面和浮层。

实施顺序：先调整辅助文字与字体层级，再统一工具栏、表单和侧栏组件，最后打磨纸面留白、阴影及短促的状态过渡。视觉记忆点集中在青色页签和引用标记，避免添加横幅、装饰卡片或循环动画。

验收时查看 1280px、1440px 桌面及窄窗口：标题不与按钮互相挤压，文字不被裁切，控件对齐，焦点清楚，已有减少动效设置继续生效。普通信息文字按 [WCAG 文字对比度要求](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)检查，目标至少 4.5:1；当前 `#8A97A3` 在侧栏底色上的对比度约 2.78:1，改为 `#5D6D78` 后约 4.98:1（按 CSS 色值计算，非全站合规结论）。

本次已实看 1280×720 的 Markdown 阅读、笔记、练习和设置弹窗；PDF 区域建议依据当前 iframe 实现，窄窗口及真实 PDF 显示效果留待美化落地后验证。
