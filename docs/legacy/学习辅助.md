# 学习辅助类项目

## 初步设计（必做）

1. 可导入`.docx`,`.pptx`,`.pdf`,`.txt`等多种常见学习资料类文件格式，并统一解析为`.pdf`文件便于后续操作。

2. 支持**笔记编辑**类工具，**思维导图**绘制类工具，后续改进可选**图形设计**类工具接入。

3. 个人基本情况填写（学历，专业，课程，相关能力基础）

## 初步设计（由调查确定）

1. 是否加入**ai辅助讲解**：用户可以任意选择一段文字/表格/图片，选择让ai对这一段单独讲解并且单轮对话可无限追问。/ai直接对整章内容讲解。

2. 是否加入ai结合全内容做**学习路径**/**课程规划**推荐。

3. 是否加入ai**辅助生成笔记**：用户手动做笔记给建议，用户可**主动**选择由ai生成笔记。

4. 是否加入ai**测试题**，并附带测试题讲解and用户自行提供测试题。

5. 若引入ai，则需要配置Ai相关功能，如记忆系统，个性化输出系统，全局约束规则等。

## 附加设计（可选）

1. 接入**邮箱mcp服务**，可以一键向任课老师或其他相关人员一键发送邮件。

2. 支持**课表导入**，可结合课表时间安排灵活安排课程设计。

3. 支持**语音/视频输入**，上课时**自动录制**教师讲解内容现场提供讲解。

4. 连接**课程网站**，一键获取课件/作业。

## 调查设计

1. 询问对ai的接受程度，是否需要引入Ai.

2. 询问个性化的定制服务。

3. 偏向做题还是偏向讲解。

4. 偏向整篇讲解还是精细化小段内容讲解。

5. 偏向自底向上的一层层深入了解还是灵活多变的临时弥补。
