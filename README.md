# 学习助手 · 本地资料学习工作台

> 把 Markdown、TXT、DOCX 或文本型 PDF 导进来，离线阅读、划选高亮、写批注和笔记；AI 是可选的助教，不配置也不影响阅读。

当前完成**第二阶段：资料导入与统一文档结构**（2026-10-22）。产品路线见 [TODO.md](TODO.md)。

---

## 1. 当前能力

| 能力 | 说明 | 需要 API？ |
|---|---|---|
| 资料导入 | 上传或放进 `library/`，支持 `.md` `.markdown` `.txt` `.docx` 和文本型 `.pdf` | 否 |
| 原文件保留 | 导入的原文件保存在 `db/originals/`；资料库文件保留原位 | 否 |
| 统一文档结构 | 各格式统一解析为规范化 Markdown 的章节/内容块，并记录来源位置 | 否 |
| 后台解析 | 任务进度、失败原因、重试；页面右侧/资料柜会显示状态 | 否 |
| 稳定文档 ID | 学习记录按文档 UUID 关联；资料库文件改名/移动后仍能匹配同一文档 | 否 |
| 阅读预览 | 所有格式都渲染为 HTML 预览，不展示 Markdown 源码；原文件只提供下载 | 否 |
| 阅读位置 | 自动保存当前位置，重新打开或重启后恢复 | 否 |
| 高亮与标注 | 选中文字或整块内容后可高亮，写批注、改颜色、定位、删除 | 否 |
| 资料笔记 | 按文档保存，自动保存 + 手动保存 | 否 |
| 划段提问 / 对话 | 现场问或放进对话；对话按文档隔离 | 是 |
| 出题与批改 | 一次一题，支持入门/中等/进阶；提交后批改并复盘 | 是 |
| 可选前置自评 | 根据当前文档生成 0～5 道前置题，可随时跳过 | 是（可不用） |
| API 设置 | 保存 OpenAI 兼容接口；Key 只显示掩码 | 否 |

无 API、离线或 AI 调用失败时：资料仍可导入、打开、阅读、标注、记笔记和保存位置，只有 AI 按钮会禁用或给出提示。

## 2. 快速开始

要求 Python 3.10+。

```bash
pip install -r requirements.txt
python launcher.py
```

打开 <http://127.0.0.1:5000>，点右上角 **导入资料**，选择一个或多个文件即可。

也可以把文件直接放进项目根目录的 `library/`，再点 **刷新资料**。首次启动会自动创建 `library/` 和学习数据库，不需要手动建库。

### 支持的格式

| 格式 | 解析方式 | 当前限制 |
|---|---|---|
| Markdown | 标题、段落、列表、代码、表格、引用、公式、相对图片 | 导入的 Markdown 不会自动复制其引用的本地图片 |
| TXT | 按空行分段 | UTF-8 优先，失败回退 GB18030 |
| DOCX | 标题层级、段落、列表、表格 | 图片以 `[图片]` 占位，不单独提取 |
| PDF | 文本型 PDF 按页提取文本 | 扫描 PDF 会明确报“没有可提取文本”；OCR 留到第四阶段 |

## 3. 阅读与标注

- 左侧资料柜：搜索、按来源分组、已读/笔记/题目状态、解析进度与失败重试。
- 中间纸面：当前文档正文；顶部显示标题、来源文件、版本号，并可打开原文件。
- 右侧批注栏：**对话 / 标注 / 笔记 / 练习 / 复盘** 五个标签。
- 选中正文文字（或点击整段/表格/代码块）会出现气泡：
  - **现场问**：回答显示在气泡里，不写入对话；
  - **放进对话**：进入当前文档的连续对话；
  - **记进笔记**：把引用追加到当前文档笔记；
  - **高亮**：创建标注，转到「标注」页写批注。
- 标注会记录引文、来源位置（页/行/段/表格）和颜色；点「定位」回到正文对应位置。

## 4. 数据与迁移

| 路径 | 内容 |
|---|---|
| `db/learning.db` | 文档、版本、章节、内容块、标注、阅读位置、笔记、对话、题目、前置题 |
| `db/originals/<doc_id>/` | 导入时保留的原文件 |
| `db/backups/phase2-*` | 从第一阶段 JSON 迁移前的备份 |
| `db/api_config.json` | API 配置（Key 明文保存在本机，接口只返回掩码） |
| `library/` | 用户手动放入的资料库文件 |
| `db/progress.json` 等旧 JSON | 第一阶段遗留文件，仅作迁移来源，不再读写 |

首次启动时如果检测到第一阶段的 JSON 学习数据，会先备份到 `db/backups/phase2-<时间>/`，再迁移到 SQLite：

- 笔记、对话、前置题、已读、当前资料、题目与上次提交；
- 文档按 UUID 关联，`legacy_rel` 记录旧路径；
- 迁移完成标记在 SQLite 的 `app_state` 中，重复启动不会重复迁移。

也可以手动执行：

```bash
python -m app.cli migrate
python -m app.cli scan
python -m app.cli library
```

**重置**只清空学习记录（已读、题目、对话、笔记、标注、位置、前置题），保留文档、原文件和 API 配置。

## 5. 后台解析与失败重试

- 导入后立即返回，解析在后台线程执行；
- 页面右上角浮条显示当前任务、阶段和进度；
- 资料柜和阅读区显示解析中/失败；
- 失败时可在资料柜点「重试」，或在阅读区点「重新解析」；
- 应用重启会把中断的解析任务恢复为待解析状态。

---

## 6. 版本与改名

- 每次导入同名文件（或资料库文件内容变化）会创建新版本，旧版本保留；
- 文档头显示 `vN`；当前版本的内容块、标注和阅读位置独立；
- 资料库文件改名/移动后，扫描会用内容哈希匹配旧文档，保持文档 ID 和笔记不丢；
- 笔记、对话按文档保存，跨版本保留；标注和阅读位置按版本保存。

## 7. AI 配置

页面右上角「API 设置」填写 OpenAI 兼容接口，默认预填 DeepSeek 格式：

| 字段 | 默认值 |
|---|---|
| API 地址 | `https://api.deepseek.com` |
| 模型 | `deepseek-v4-flash` |
| 超时 | 180 秒 |
| 温度 | 0.7 |

- 配置优先级：`db/api_config.json` > 环境变量 `LLM_*` > 默认值；
- 保存时 Key 留空表示保留旧 Key；有 Key 时可显式勾选清除；
- 页面和接口只返回掩码，不返回完整 Key；
- 未配置 API 时阅读、标注、笔记、位置保存都不受影响。

使用 AI 时，当前文档内容、划选、对话、笔记与批改上下文会发送到你配置的模型服务商；应用本身不上传资料到自有服务器。

## 10. 已知限制

- DOCX 图片只以 `[图片]` 占位；Markdown 导入不会携带其引用的本地图片；
- 原文件入口是下载，不在页面里再展示 Markdown/纯文本源码；
- 超大的 PDF 会一次性渲染整份内容，页面可能较大；按页懒加载留到后续优化；
- 扫描版 PDF 不支持，会明确提示；OCR 在第四阶段；
- 还没有版本选择器，旧版本内容保留在数据库中但 UI 只显示当前版本；
- 文档内容更新后，前置题缓存和对话上下文可能沿用旧内容；第四阶段处理缓存失效；
- 没有文档删除/重新命名 UI；资料库文件改名由扫描自动匹配；
- 没有登录/权限，服务默认只监听 `127.0.0.1`；
- Flask 开发服务器仅适合本机单用户；
- 打包暂缓，但打包配置已移除旧课程资源。
